# 🔗 Link in Bio - Armando Castellan Neto

Página de links estilo Linktree com design técnico baseado no SDD.

## 🌐 Acesso

**URL:** https://armandocas.github.io/linkinbio

## ✨ Características

- 🎨 Design com paleta SDD (Precision Cartography)
- 📱 Totalmente responsivo
- ⚡ Sem dependências, apenas HTML/CSS puro
- 🚀 Hospedado no GitHub Pages (grátis)
- ⚙️ Fácil de editar

## 🔧 Como Adicionar Novos Links

Edite o arquivo `index.html` e adicione novos links usando este template:

```html
<a href="SUA_URL" class="link-card" target="_blank" rel="noopener noreferrer">
    <div class="link-icon" style="background: linear-gradient(135deg, #1D4ED8, #7C3AED);">
        🎯
    </div>
    <div class="link-content">
        <div class="link-title">Título do Link</div>
        <div class="link-description">Descrição curta</div>
    </div>
    <span class="link-arrow">→</span>
</a>
```

## 🎨 Customização

### Cores do Gradiente:

- **Azul/Roxo:** `background: linear-gradient(135deg, #1D4ED8, #7C3AED);`
- **Azul/Ciano:** `background: linear-gradient(135deg, #1D4ED8, #0F766E);`
- **Amarelo/Laranja:** `background: linear-gradient(135deg, #F59E0B, #B45309);`

### Badge "NOVO":

Para destacar um link, adicione antes do ícone:

```html
<div class="featured-badge">NOVO</div>
```
