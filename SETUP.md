## 🔧 COMO ADICIONAR MAIS LINKS

Edite o arquivo `index.html` e adicione este código dentro de `<div class="links">`:

```html
<a href="SUA_URL" class="link-card" target="_blank" rel="noopener noreferrer">
    <div class="link-icon" style="background: linear-gradient(135deg, #1D4ED8, #7C3AED);">
        🎯
    </div>
    <div class="link-content">
        <div class="link-title">Título do Link</div>
        <div class="link-description">Descrição breve</div>
    </div>
    <span class="link-arrow">→</span>
</a>
```
